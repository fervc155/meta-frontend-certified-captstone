# Little Lemon Booking App

## Overview

This project is a table reservation web application for the Little Lemon restaurant built with React.

## Features

- Table reservation form
- Dynamic available times based on selected date
- Form validation (HTML5 + React)
- Accessibility improvements (ARIA, semantic HTML)
- Unit testing with Jest

## Installation

```bash
git clone <your-repo-url>
cd meta-frontend-certified-captstone
npm install
npm start
```
